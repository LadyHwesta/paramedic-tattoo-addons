# Practitioner Suite - Paramedical Tattoo Pack

Sets the Practitioner Suite up for a paramedical or medical tattoo practice:
treatment types (areola restoration, scar camouflage, scalp
micropigmentation, vitiligo repigmentation), a pigment patch test read after
three days, health flags (bleeding disorder, blood thinners, keloid history),
tattoo consent wording, the related surgery date on a treatment plan and the
numbing agent used in a session. All of it is ordinary data the practice can
edit afterwards.
