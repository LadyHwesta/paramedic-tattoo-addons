# eLearning: Notes and Photo Permissions

A short course for Practitioner Suite staff, installed with
`practice_client_portal` and `practice_elearning` (auto-install): internal
and shared clinical notes, sharing photos with a client, and permission to use
a photo in marketing. Members only, by invitation, for the staff group.

The data file is generated: edit `tools/build_course_data.py` and run it from
the repository root. Screenshots in `static/img` are from a local test database
with sample data (no real clients).

3 tests: the course is built and gated, every lesson is published, and every
screenshot exists.
