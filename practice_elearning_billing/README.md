# eLearning: Billing Clients

One course for whoever bills clients, built into the eLearning app on install
(members only, by invitation, for invoicing users), with a quiz and screenshots
from a sample practice ("Juniper Restorative Studio"):

- **Prices and invoices**: a price on each service, Create Invoice on a
  completed appointment, several visits at once.
- **Getting paid**: Pay on the invoice at the desk, the Payment column and
  the To Invoice filter, payment reminders.

Teaches `practice_billing`. The data file is built by
`tools/build_course_data.py`: edit the lessons there and rerun it when a
screen changes. Screenshots are in `static/img`.
